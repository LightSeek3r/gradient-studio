First release (0.1.0). Stylelint rules `opal42/min-score` (no default
threshold), `opal42/no-finding` and `opal42/valid-gradient`, with an opt-in
`--fix` that only rewrites a single, fully scorable gradient when the rewrite
strictly raises its smoothness score.
