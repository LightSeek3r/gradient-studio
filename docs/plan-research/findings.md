# Gradient Studio — consolidated findings from 6 research/audit subagents (Nov 2026)

Source reports: 2x Haiku 5.5 code audits (A, B), 4x Sonnet 5.5 research slices (C libs, D browser/design, E OS/CLI/editors, F platform/AI/business). Items marked (U) = unverified by the reporting agent. Agents disagree in a few places; conflicts are listed at the end.

## A. Engine audit (Haiku) — /home/user/gradient-studio/src
- gradient-engine.ts 713 lines, color-formats.ts 483, clipboard.ts 40. Engine+formats: no DOM/Node globals, no Math.random/Date. Only clipboard.ts is browser-bound (adapter). Hidden module state: `namedLabs` lazy cache (color-formats.ts:189-196). Clamp duplicated (engine:7-9, formats:22-24).
- Exports: conversion (srgbToLinear, linearToSrgb, rgbToOklab, oklabToLinearRgb, oklabToRgb, oklabToLch, lchToOklab, hexToOklch, oklchToHex), parse/format (parseHex/Rgb/Hsl/Name/AnyColor, nearestColorName, formatHex/Rgb/Hsl/Name, CSS_NAMED_COLORS 148), HSL funcs, gamutFitOklch/oklchToHexFitted/complementHex, scoreGradient(ticks), suggestGradient(ticks), buildGradientCSS(ticks, angle), buildMultiGradientStyle, spreadDirectionAngles, interpolateGradient(ticks, n), MAX_DIRECTIONS=7.
- API smells: mixed units (RGB 0-255, linearToSrgb 0-1 in/0-255 out, HSL s/l 0-100, position 0-100, weight 1-100 unenforced); hex-string-only inputs everywhere; hexToRgb returns NaN silently; parsers return null; NaN yields "#NaNNaNNaN"; "#ccc" sentinel for empty; silent sRGB clipping in suggest/interpolate (only complements gamut-map); ~35 magic-number thresholds/weights in scoreGradient (weights 30/30/20/20); issues are free-text English strings (22 sites), not codes; GradientStyle mirrors React style prop; formatName adds "~"; plain-object lookups CSS_NAMED_COLORS[key] / HEX_TO_NAME could return Object.prototype members ("constructor") — needs a test; parseHsl heuristic treats bare values <=1 as fractions; inconsistent achromatic thresholds (0.02 vs 0.04/0.08) leave a gap.
- No tests anywhere; no test script; tsconfig.app.json includes DOM lib so engine wouldn't fail typecheck if it touched DOM.
- Hot spots to test first: hue wraparound (engine:150,301,331,526,543-544; circular mean degenerate for opposed hues), division guards (279,402,483,700), interpolateGradient frac extrapolation beyond last stop (689-700), gamutFitOklch bisect (16 iters; L outside 0-1 never passes), srgbToLinear negative/NaN.

## B. App audit (Haiku)
- App.tsx owns all state in six useState hooks; no context/reducer; ids from module-level counters. No single "document" type: ticks: GradientTick{id,color #rrggbb,position 0-100}[], directions: GradientDirection{id,angle,weight 1-100,enabled}[], blend: GradientBlendMode (9 values). Not modelled: stop-bar angle (hardcoded 90), interpolation space, alpha, per-stop names.
- No persistence, URL/hash state, import, undo/redo, presets, saved gradients. Export is copy-only.
- Reusable: ColorTextField/NumericTriple (fields.tsx), StopCard, DirectionsPanel. Needs clipboard adapter injection: CopyButton/PasteButton/FlashButton. Not reusable: App.tsx (logic inline, window listeners, imports App.css); index.css global `*`/body styles leak.
- Styling: dark-only CSS vars, no prefers-color-scheme; breakpoints 860/600px; hard-coded widths (studio 940, preview 280px, compass 168px) — 400px popup likely OK, 320px probably overflows (unverified).
- No i18n (all English inline; product page is EN+FR externally). a11y: aria on most inputs, but stop-bar tick-handle is mouse-only (no tabIndex/role/keyboard), compass pointer-only, no :focus-visible (outline:none on fields/slider), no reduced-motion, no aria-live for score.
- Build: Vite 7 SPA, React Compiler, `private:true`, v0.1.0, no library mode/base. CI: lint+build on push/PR, Node 24, SHA-pinned actions. Missing: tests, a11y lint, library/d.ts build, release automation, deploy config in repo (Cloudflare Pages deploy not in repo).

## C. Libraries & packages (Sonnet)
- Core extraction is root dependency for everything. Add before 1.0: issue codes {code,severity,stopIndex?,message}; scoreCSS/parse of full `linear-gradient(...)`; alpha + oklch/hsl/name input colors; optional id; `in oklch` CSS output.
- Names: registry.npmjs.org 404 for gradient-studio, @gradient-studio/core, gradient-score, oklch-gradient, perceptual-gradient; PyPI/crates 404 for gradient-studio. npm org/JSR scope not verified claimable. Action: claim now.
- Build/publish: ESM first (dual CJS cheap), exports map (".", "./color", "./score", "./css"; split 148-name table for tree shaking), sideEffects:false, size budgets (core <=4KB gz, formats+names <=3KB gz — targets, unmeasured), size-limit+publint+arethetypeswrong in CI, JSR with explicit return types (slow-types rule), npm Trusted Publishing (OIDC, npm >=11.5.1) + changesets. Semver: scoring weights are API — change = minor + changelog; golden vectors are the contract.
- Ports: language-neutral spec + golden JSON vectors generated from TS reference (exact equality for hex/CSS, ±0.5 score). Order: Python(S) → Rust(M) → Swift(M) → Kotlin(M); Dart/.NET/Go on demand; skip Ruby/PHP. WASM/UniFFI/AssemblyScript not worth it for ~40KB of math; revisit only if >4 ports.
- Wrappers: Web Component <gradient-score>/<gradient-field> first; React hook second; Vue/Svelte/Solid = docs snippets; skip Angular. Do not publish five wrapper packages.
- Ecosystem: Stylelint plugin (highest differentiation, value 5, M); PostCSS plugin (overlaps postcss-easing-gradients, @csstools gradients-interpolation-method — stay on "score+refine" niche); Tailwind v4 plugin (S-M); DTCG/Style Dictionary transform (check spec shape first); skip Sass; CSS-in-JS = recipe; ESLint rule later (ESLint v9 EOL 2026-08-06); CLI.
- Competitors: culori, Color.js, chroma.js (color math); postcss-easing-gradients, Josh Comeau article (fixes without diagnosis). None SCORE a gradient or name why it's bad → differentiation. Position as quality metric/linter on top of culori/Color.js, not a replacement. Avoid competing on color-space coverage; publish scoring rationale/weights, ideally validate with human ratings.

## F. Platform / AI / generative / business (Sonnet)
- Scoring logic assumes browsers interpolate in sRGB (comment ~engine:386); buildGradientCSS emits plain linear-gradient, no `in oklch`. CSS gradient interpolation (`in oklch`/`in oklab`) Baseline "newly available" since 2024-06-11, widely available ~Dec 2026 by 30-month rule. IMPLICATION: "smoother OKLAB gradients" stops being a differentiator; value shifts to JUDGING & CHOOSING: which stops, chroma/hue travel, banding/dead zones, interpolation space + hue path (shorter/longer), gamut and contrast. Response [S-M, value 5]: add `interpolation: srgb|oklab|oklch` param to scoreGradient (scoring-model change, not just export), emit `linear-gradient(in oklch, …)` with sRGB fallback line, honest README line ("your browser can interpolate; we tell you whether it should").
- AI-agent surfaces = strongest niche ("purple gradient" LLM slop; almost no benchmark measures taste; deterministic explainable scorer fits). MCP spec latest 2026-07-28, stateless, no initialize handshake; Cloudflare says use stateless createMcpHandler at /mcp for new servers. MCP Registry = metadata catalog (publish server.json via mcp-publisher after npm version exists). Claude directory submission portal claude.ai/directory/manage. ChatGPT apps open (U). Skills = SKILL.md folder, open standard (~40 tools read it; field details from mirrors). Plan: MCP server (score_gradient, refine_gradient, complement, render_preview as SVG) shipped stdio via npx AND remote Worker; Agent Skill `gradient-quality` (cheapest agent surface, no hosting; rule: score before emitting gradient, refine if <70); GradientBench (≈100 UI briefs, model-agnostic harness, leaderboard, before/after skill run; label as perceptual smoothness not aesthetics) [M,4, best awareness driver].
- Hosted API (Cloudflare Worker, Hono, POST /v1/score|refine|css|complement, OpenAPI 3.1): mostly NOT needed; only for non-JS clients/no-code (Zapier/Make/n8n/Notion/Airtable/Shortcuts). Free plan 100k req/day, 10 ms CPU (scoring time (U) — benchmark). No keys on free tier. Privacy wording must change: "stateless: no storage, no body logging, no cookies"; Cloudflare still sees IPs; don't say "no data leaves your device" for the API. Demand-gated [S,2].
- Exports: Tailwind v4, CSS-in-JS, SVG, DTCG JSON (DTCG 2025.10 stable; gradient shape unconfirmed — read spec), pre-sampled stops (8-16, via interpolateGradient) as universal export for SwiftUI/Compose/Flutter/Godot/Unity (SwiftUI Gradient.ColorSpace has device/perceptual only; Compose Brush no interpolation-space option and falls back to sRGB; Flutter none; Godot Gradient has OKLAB mode (U)). Satori OG route later [M,2]. Skip: Lottie, wallpaper generator, palette-from-image, text-to-gradient (needs LLM; agent surfaces cover it better).
- Business: keep MIT for engine/CLI/MCP/skill; web app free. GitHub Sponsors; optional paid hosted API tier with keys (never in web app). "Gradient Studio" is generic & already used (Peerlist project, Taskade templates, a near-identical ChatGPT app "Gradients Studio") — can't own it; brand library/CLI/MCP distinctively under Unit42; check INPI/EUIPO/USPTO (U). Supply chain: npm classic tokens gone → Trusted Publishing OIDC + provenance, 2FA, SHA-pinned actions, CODEOWNERS, branch protection, second maintainer/recovery contact; extension store accounts get phished → hardware keys, dedicated account, defer extensions until library stable. Telemetry: none, state in PRIVACY.md; measure via npm downloads/stars. Governance: roadmap + scope doc (pure functions, no network, no storage in core).

4. Hosted API: F says demand-gated; C/E rely on none. Remote MCP implicitly needs a Worker anyway.
5. Many facts are (U): fees, review times, Figma Dev Mode/Make, Compose/SwiftUI interpolation, Tailwind/Style Dictionary specifics, trademark — plan must include a verification checklist rather than assert them.
